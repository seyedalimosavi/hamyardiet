1. **برگه اول (برنامه غذایی روزانه — حداکثر ۲ صفحه A4):** از تب «برگه چاپ برنامه غذایی (≤۲ صفحه A4)» دکمه چاپ را بزنید. این برگه بدون باکس مجزای وضعیت روغن بوده و سهم روغن و معادل نان به صورت طبیعی داخل خط غذا درج شده است.
